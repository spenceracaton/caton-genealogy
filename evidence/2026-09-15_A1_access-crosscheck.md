# A1 — Fauquier personal-property tax, 1833–1840: access cross-check

## Question

Does the Fauquier personal-property tax list place a second or third tithable
under Thomas Caton in 1836–39, when Aaron and Joseph would have reached the
taxable age used by the list?

## Retrieval boundary

The FamilySearch Full-Text Search query was submitted with `Caton`, place
`Fauquier, Virginia`, and years `1833–1840`. The site redirected to its
identity sign-in page before exposing a result list or image. A direct
FamilySearch catalog route for the Fauquier tax film likewise redirected to
identity sign-in. No tax page or entry was retrieved.

Ancestry's public collection page for [Virginia, U.S., Personal Property Tax
Records, 1782–1900](https://www.ancestry.com/search/collections/62774) exposes
the Fauquier browse set and an `1833–1845` image-set link. Opening that image
set redirected to Ancestry's membership page. No image was read there, and no
subscription, credential, or paywall workaround was attempted.

## Finding and limit

This is an access result only. It neither supports nor weakens the hypothesis
that Thomas Caton carried Aaron and Joseph as tithables. A1 remains open for a
signed-in FamilySearch session or an image copy obtained through a library or
archive. The existing 1800–1832 tax run (C156) is not extended by this check.
